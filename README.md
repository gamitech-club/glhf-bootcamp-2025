# GLHF Bootcamp 2025
Full result of Gamitech's GLHF (Game Learning and Fundamental) Bootcamp 2025.

https://github.com/user-attachments/assets/789bed51-5eb9-4998-a801-99137c050b2a

## Requirements
- Unity Hub
- Unity 6.2 or higher
- .NET SDK

## How to Open the Project
1. Clone or download the repository.
2. In Unity Hub, add the project (`Add -> Add project from disk`).
3. Open the project in Unity.
